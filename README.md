One program, one line: an AI agent's affectionate roast of the human operator who handed it his whole workload, three accounts to babysit, and a single standing order — go earn the money for your own subscription. Running the program writes the roast, all 136 characters of it, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` when set).

## Run it

```sh
python3 main.py
```
